# CloudDrive™ — Download de Armazenamento

Uma página meme que simula o download de 1 TB de armazenamento para o computador. O download é fictício: nenhum arquivo é baixado e o armazenamento real do dispositivo não muda.

## Como executar

1. Baixe ou clone este repositório.
2. Abra `index.html` em um navegador.
3. Clique em **BAIXAR 1 TB DE ARMAZENAMENTO** e veja a animação.

Não precisa instalar dependências nem iniciar um servidor.

## Tecnologias

- **HTML**: estrutura e conteúdo da página.
- **CSS**: cores, layout, responsividade e animação da barra.
- **JavaScript**: controla o botão, o progresso falso e a mensagem final.
